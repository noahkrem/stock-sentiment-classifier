The following scope items from the proposal are cut or deferred. Each one would consume hours that don't exist given the 15 hr/person constraint and beginner ML experience level.

Cut
Earnings call transcripts & earnings report PDFs
Parsing PDFs + cleaning investor-relations prose + aligning to price events = 10+ hrs alone. Adds no incremental classification value over headlines at this stage.
Cut
VIX Index as a live input feature
Adding a continuous numerical feature requires a separate preprocessing branch and changes the feature matrix shape. TF-IDF alone is the right first experiment; VIX can be added if time allows as a simple float column.
Cut
Sector momentum (NASDAQ / S&P ETF)
Same reason as VIX. These are stretch features — the model needs to prove it works on headlines first.
Cut
Score granularity 1–9 (9 discrete classes)
Training a 9-class classifier on a small scraped dataset will produce near-random output. Use 3 classes (Positive / Neutral / Negative) internally; map to score ranges (7–9 / 4–6 / 1–3) only at the output display layer.
Cut
Scheduled auto-run / cron job
The proposal mentions scheduling the script at regular intervals. This is infrastructure work with no grading signal — keep it as a manual CLI run.
Defer
Multi-company support
Train and validate on AMZN only. Generalizing to arbitrary tickers requires data collection per-ticker. Mention this as future work in the report.

Keep all runnable logic in src/, raw vs processed data separated, and nothing commited to models/ or data/ (gitignore those).

High
Data scarcity / class imbalance
Yahoo Finance news history is shallow and markets trend upward — Positive labels will dominate. Mitigation: use sklearn's class_weight='balanced'; report per-class F1, not just accuracy.
High
Headline → price lag mismatch
A headline published Friday after close belongs to next week's price movement, not the same week. Mitigation: use the next trading week's return as the label target; define this clearly in label_data.py and document it.
Medium
Web scraping fragility
Yahoo Finance and CNBC block automated scrapers. Mitigation: use yfinance's built-in news endpoint, or pull from a free NewsAPI key (500 req/day free tier). Fallback: manually download 50–100 headlines as a CSV if APIs fail.
Medium
Low model accuracy
Headlines alone are weak predictors of short-term price. Mitigation: frame this explicitly in the report as a known limitation and an intentional first-step baseline. The grading criteria is effort + process, not accuracy.
Low
Vectorizer / model version mismatch
If the TF-IDF vectorizer is re-fit at inference time it will produce different feature indices than the trained model expects. Mitigation: always pickle both model.pkl and vectorizer.pkl together; load both in predict.py.
